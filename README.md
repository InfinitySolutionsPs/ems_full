# نظام إدارة عمليات الإسعاف والطوارئ – PRCS EMS

نظام ويب عربي لإدخال بلاغات الإسعاف، حفظها في قاعدة بيانات مركزية، عرض المؤشرات التفاعلية، وإصدار التقارير التشغيلية.

## الوظائف الحالية

- تسجيل بلاغ إسعاف كامل وبيانات المستفيد والحالة والموقع.
- تسجيل المحطة والمركبة والطاقم والتوقيتات والتدخلات.
- حساب زمن الاستجابة وزمن الخدمة والمسافة تلقائيًا.
- لوحة مؤشرات وفلاتر حسب التاريخ والمحافظة والتصنيف.
- سجل مركزي للبلاغات مع البحث.
- تقارير تشغيلية وتقارير المحطات والأسطول والمستفيدين.
- تصدير البيانات بصيغة CSV متوافقة مع Excel.
- جداول للمحطات والمركبات والطاقم والمستخدمين وسجل التدقيق.
- دورة اعتماد كاملة: جديد، معتمد، أو معاد للتصحيح.
- إشعارات تلقائية عند الإدخال والاعتماد والرفض.
- إدارة المستخدمين بأدوار مدير النظام والموظف المركزي ومدخل المحطة ومشاهد التقارير.
- صفحة إعدادات فعّالة للمحطات والمركبات والطواقم وخيارات النظام.
- واجهة RTL متجاوبة مع الهاتف والحاسوب.

## التشغيل المحلي

```bash
npm ci
npm run dev
```

## قاعدة البيانات

مخطط البيانات موجود في `db/schema.ts`، وملف الترحيل في مجلد `drizzle`. النسخة المنشورة تستخدم قاعدة D1. يمكن نقل المخطط لاحقًا إلى PostgreSQL عند النشر على خادم VPS.

## استيراد البيانات التاريخية

لم تُضمّن بيانات المرضى في الكود. ملف الإكسل المرفق سابقًا يحتوي النماذج والقوائم المرجعية، بينما ورقة البلاغات فيه فارغة. عند توفير ملف السجلات الفعلي يمكن تحويله واستيراده مع منع تكرار رقم البلاغ ومراجعة المجاميع قبل الاعتماد.
